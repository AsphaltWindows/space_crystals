# 0163 — Simultaneous last defeats are a draw

- **Date**: 2026-11-24T20:30:00-05:00
- **Answers**: Q0036 (point 1)
- **Docs**: `core/game_rules.md > End of Game` (Draw)

## What changed and why
Option A. If every remaining side is defeated in the same tick, the game ends as a draw: no winner, everyone sees "Draw" (players defeated earlier too).

## Implementation impact
Replaces "everyone sees Defeat" for this case.

## Verification
Two players destroy each other's last building in the same tick: both see "Draw"; replay saved.
