# Syndicate: Units

**Syndicate lasers are red** (user, 2026-11-25): every Syndicate laser-shooting unit and structure (Guard, Laser Battery, Laser Turret) fires a **red** laser.

## Files

- `guard.md` — **Guard**: Basic laser infantry, ground+air (Optics Lab)
- `grenadier.md` — **Grenadier**: Grenade AoE infantry (Chemical Plant)
- `agent.md` — **Agent**: Worker: pistol, crystal/Supplies gathering, building (Tunnel Construction Flow)
- `assault_bike.md` — **Assault Bike**: Fastest wheeled vehicle, mortar turret
- `shadebringer.md` — **Shadebringer**: Support vehicle: Sludge and Cover (smoke) toggles (Vault)
- `laser_battery.md` — **Laser Battery**: Battery-powered laser tank; Amplify, Deploy (AA), Relay through Prisms
- `subterranean_transport.md` — **Subterranean Transport**: Infantry transport that burrows (DrillUnit, Forge)
- `phantom.md` — **Phantom**: Hovering laser aircraft, ground+air (Optics Lab)
- `specter.md` — **Specter**: Single-payload glider bomber; re-arms in Tier 3 Tunnels (Vault + Chemical Plant)
- `prism.md` — **Prism**: Satellite: laser relay, one-way launch, thrust charges (Orbital Command)
