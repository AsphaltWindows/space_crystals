# Cults: Overview

## TheCults
The Cults are a faction that spreads across the map through Recruitment Halls, drawing free Recruits from Recruitable terrain. Recruits serve as both workers and the base unit that is trained into all other Cult units, and they build every Cults structure. Larger units such as vehicles consume multiple Recruits during training, and their Unit Control cost scales accordingly (one per Recruit consumed). Army size scales with territorial control of Recruitable tiles, with no hard cap.

## CultsResources
The resources available to a Cults player.

### Space Crystals
Core resource. Gathered from Space Crystals Patches by Recruits. Spent on buildings, units, and upgrades.

### Unit Control
Provided by Recruitment Halls in proportion to the number of Recruitable tiles each hall is actively recruiting from. No hard cap — army size is bounded only by territorial control of Recruitable land. Each Cult unit has a Unit Control cost. The player cannot build units if doing so would exceed the total available Unit Control.
