# QA Router -- Automated QA Capabilities
#
# Each non-comment, non-empty line is a grep pattern (basic regex).
# If ALL QA instruction lines in a qa_item match at least one pattern,
# the item is routed to automatic_qa. Otherwise it goes to manual_qa.
#
# Patterns are matched case-insensitively via grep -qi.
#
# Updated: 2026-03-28 by software_architect
# Strategy: Only route items that are genuinely automatable — i.e.,
# instructions that involve running cargo commands, checking compilation,
# or running tests. Interactive gameplay verification (select units,
# click buttons, observe visual behavior) must go to manual_qa.
#
# IMPORTANT: Do NOT add broad single-word verb patterns (verify, check,
# select, build, click, etc.) — they match virtually ALL QA instructions
# and cause interactive items to be misrouted to automatic_qa.
#
# --- Build/test commands ---
cargo test
cargo check
cargo clippy
compile
run.*test
unit test
integration test
