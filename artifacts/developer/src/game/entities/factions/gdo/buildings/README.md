# GDO Buildings

Entity definitions for GDO faction structures.

## Files

- **base.rs** — DeploymentCenter and PowerPlant (core infrastructure)
- **military.rs** — Barracks and SupplyTowerDef (military production)
- **extraction.rs** — ExtractionFacility and ExtractionPlate (resource extraction)
- **types.rs** — Shared types for this module (currently empty)
- **utils.rs** — Shared utilities for this module (currently empty)
