# Cults Units

Entity definitions for all Cults faction units.

- `recruit.rs` — CultsRecruit: unarmed gatherer/builder unit (auto-produced by RC)
- `soldier.rs` — CultsSoldier: melee combat unit placeholder (trained from Armory)
- `gunner.rs` — CultsGunner: ranged combat unit placeholder (trained from Armory)
- `types.rs` — Shared types for Cults units
- `utils.rs` — Shared utilities for Cults units
